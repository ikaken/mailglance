# ログインエラーの対処

mailglance のエラー欄に「（エラーコード）」付きのメッセージが出たときの、意味と対処です。メッセージ末尾のカッコ内のコードで、該当する項目を探してください。

## invalid_client：クライアント シークレットが正しくありません

**意味**: Google に送ったクライアント シークレットが、Google Cloud の登録内容と一致していません。

**主な原因**

- シークレットをコピーしたときに、前後の空白や改行が入った、または途中が欠けた。
- Google Cloud でシークレットを作り直した、または古いものを無効化・削除した。
- クライアント ID と別のクライアントのシークレットを組み合わせている。
- クライアントの種類が「デスクトップ アプリ」ではない。

**対処**

1. https://console.cloud.google.com/auth/clients を開き、設定画面と同じクライアント ID のクライアントを開く。種類が「デスクトップ アプリ」であることも確認する。
2. 「クライアント シークレット」をコピーする（ステータスが「有効」のもの）。
3. mailglance の設定画面で、クライアント シークレット欄に貼り付けて「保存」を押す。この欄は保存済みの値を表示しないので、新しく入力すれば上書きされる。
4. 続けて下の「invalid_grant」の手順でアカウントを追加し直す。

クライアント ID が Google Cloud に見つからないときは、ID とシークレットの両方を新しいものに入れ替える（手順は [Google Cloud クライアント ID 取得手順](Google%20Cloud%20クライアント%20ID%20取得手順.md)）。

## invalid_grant：ログインの有効期限が切れました

**意味**: 保存してあったログイン情報（リフレッシュ トークン）を Google が受け付けませんでした。

**主な原因**

- OAuth の公開ステータスが「テスト」のまま。この場合、約 7 日でログインが切れる。
- クライアント シークレットを作り直した、またはクライアントを作り直した。
- Google アカウントのパスワードを変えた。
- Google アカウントの「サードパーティのアクセス」で mailglance を削除した。

**対処**

1. mailglance の設定画面を開く。
2. 対象のアカウントを削除する（Gmail のメールは消えません）。
3. 「アカウントを追加」を押し、ブラウザで Google にログインして許可する。「Google はこのアプリを確認していません」と出たら、「詳細」→「（アプリ名）に移動」で進む。

**繰り返し切れるとき**

https://console.cloud.google.com/auth/audience で公開ステータスを「本番環境に push」にすると、7 日での失効はなくなる（未確認アプリの警告は出たまま）。「テスト」と「本番環境」のどちらかは同じ画面で分かる。

## access_denied：ログインが中止されました

**意味**: Google のログイン画面で拒否された、またはキャンセルされました。

**主な原因と対処**

- 公開ステータスが「テスト」のとき、ログインしようとしたアドレスがテストユーザーに入っていない。https://console.cloud.google.com/auth/audience の「テストユーザー」にそのアドレスを追加する。
- 許可の画面で「キャンセル」を押した。もう一度「アカウントを追加」からやり直す。

## ログイン情報がありません

**意味**: このパソコンに、そのアカウントのログイン情報が保存されていません（Windows の資格情報マネージャーから消えた、別のパソコンに設定を移した、など）。

**対処**: 「invalid_grant」と同じ手順で、アカウントを追加し直す。

## どれにも当てはまらないとき

エラー文の全文（コードを含む）を控え、次を確認する。

1. Gmail API が有効になっているか（https://console.cloud.google.com/apis/library/gmail.googleapis.com）。
2. クライアント ID とシークレットが同じクライアントのものか。
3. インターネットに接続できているか。

それでも直らない場合は、[Google Cloud クライアント ID 取得手順](Google%20Cloud%20クライアント%20ID%20取得手順.md) を最初からやり直して、新しいクライアントを作る。
